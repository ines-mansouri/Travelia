# Flight Metasearch Engine — MVP

A minimum viable product for a flight metasearch engine (like Kayak/Skyscanner) built with **Next.js 14 (App Router)**, **TypeScript**, and the **Amadeus Self-Service API (free tier)**.

## Architecture Overview

```
User Browser                    Next.js Server                    Amadeus API
     │                              │                                │
     │  /flights/JFK-LAX/...        │                                │
     │─────────────────────────────>│                                │
     │                              │  POST /v1/security/oauth2/token│
     │                              │───────────────────────────────>│
     │                              │<────── access_token ──────────│
     │                              │                                │
     │                              │  GET /v2/shopping/flight-offers│
     │                              │───────────────────────────────>│
     │                              │<────── FlightOffer[] ─────────│
     │                              │                                │
     │  ┌─ Normalise offers         │                                │
     │  ┌─ Sort by "Best" algorithm │                                │
     │  ┌─ Generate affiliate links │                                │
     │                              │                                │
     │<──── HTML / JSON results ────│                                │
     │                              │                                │
```

### Data Flow

1. **URL Routing** — Catch-all route `/flights/[slug]` parses `JFK-LAX/2025-09-15/2025-09-22`
2. **API Layer** — `/api/search` calls Amadeus, normalises → sorts → returns JSON
3. **Sort Algorithm** — Min-max normalised weighted score: 50% price + 35% duration + 15% stops
4. **Affiliate Links** — `/api/redirect` builds OTA outbound URLs and 302-redirects
5. **Static Data** — OurAirports CSV → `public/data/airports.json` for autocomplete

## Getting Started

### 1. Install dependencies

```bash
cd flight-metasearch
npm install
```

### 2. Get Amadeus API credentials

- Go to https://developers.amadeus.com
- Register → "Flight Offers Search" API (Test/Free tier)
- Copy your **API Key** and **API Secret**

### 3. Configure environment

```bash
cp .env.example .env
```

Edit `.env`:
```env
AMADEUS_API_KEY=your_key_here
AMADEUS_API_SECRET=your_secret_here
AFFILIATE_PARTNER_ID=your_affiliate_id   # optional for MVP
```

### 4. Download airport data (optional — for autocomplete)

```bash
npm run download-airports
```

This fetches the OurAirports CSV and generates `public/data/airports.json`.

### 5. Start the dev server

```bash
npm run dev
```

Open http://localhost:3000

### 6. Try a search

Visit directly: http://localhost:3000/flights/JFK-LAX/2025-09-15/2025-09-22

Or use the search form on the homepage.

## API Reference

### `GET /api/search`

| Param      | Type   | Required | Description |
|-----------|--------|----------|-------------|
| origin    | string | yes      | IATA code (3 letters) |
| destination | string | yes    | IATA code (3 letters) |
| deptDate  | string | yes      | YYYY-MM-DD |
| returnDate | string | no      | YYYY-MM-DD (omit for one-way) |
| adults    | number | no       | 1–9 (default 1) |
| sort      | string | no       | "best" (default), "price", "duration" |
| max       | number | no       | Max results (default 50, max 250) |

### `GET /api/airports?q=`

| Param | Type   | Required | Description |
|-------|--------|----------|-------------|
| q     | string | yes      | Search query (min 2 chars) |

### `GET /api/redirect`

Redirects to an affiliate partner URL. Params: `offerId`, `origin`, `destination`, `deptDate`, `returnDate`.

## "Best" Sort Algorithm

The algorithm balances price and travel duration using min-max normalisation:

```
bestScore = 0.50 * priceNorm + 0.35 * durationNorm + 0.15 * stopsNorm
```

Each component is normalised to [0, 1] across the result set. Lower score = better deal. This surfaces the cheapest short flights while still ranking ultra-long hauls fairly when price is significantly lower.

## Production Considerations

- **Database**: Replace static `airports.json` with a PostgreSQL table + `pg_trgm` index for fuzzy search at scale
- **Caching**: Add Redis to cache Amadeus responses (TTL 5–10 min) to stay within rate limits
- **Affiliate Network**: Integrate Travelpayouts, Skyscanner Associates, or Booking.com affiliate program for commission tracking
- **Rate Limiting**: Amadeus test tier allows ~1 req/sec — use a queue or token bucket in production
- **Error Handling**: Retry with exponential backoff on 429/5xx from Amadeus
